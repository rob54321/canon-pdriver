1. 소개
"Linux용 Canon UFR II/UFRII LT 프린터 드라이버"는 Canon 디바이스를 지원하는 Linux 운영 체제 프린터 드라이버입니다. 이 드라이버는 Linux 운영 체제용 CUPS(Common UNIX Printing System)를 사용합니다. 이 드라이버를 설치하면 GUI(Graphical User Interface) 설정 화면과 명령줄에서 내장 디바이스 기능으로 인쇄할 수 있습니다.

4. 프린터 드라이버 설치
컴퓨터가 인터넷 환경에 연결되어 있는지 확인한 후 드라이버를 설치하십시오.
드라이버 설치 방법과 사용 방법에 관한 자세한 내용은 사용자 안내서를 참조하십시오.(→ UFR II/UFRII LT 프린터 드라이버 사용자 안내서)
설치 주의사항은 "사용 시 주의사항" > "1. 설치 중 제한(모든 배포 공통)" 또는 "2. 설치 중 제한(배포별)"을 참조하십시오.
사용 시 주의사항
1. 설치 중 제한(모든 배포 공통)
인쇄에 사용한 캐시 파일이 "cngplp2"에 남아 있는 상태로 드라이버 패키지를 제거하는 경우, "cngplp2"가 삭제되지 않기 때문에 경고가 표시됩니다. 캐시 파일을 삭제할 필요는 없습니다. 캐시 파일을 삭제하려면 "cngplp2"를 수동으로 삭제하십시오.
USB를 연결하여 프린터를 사용하고, 한 대의 컴퓨터에 여러 대의 프린터를 연결하여, 인쇄 대기열을 등록할 경우, 제대로 인쇄되지 않거나 정보를 가져오지 못할 수 있습니다. 이러한 현상은 한 대의 컴퓨터에 한 대의 프린터만 연결하여 방지할 수 있습니다.
iR C1021/C1021i, MF8400 시리즈, MF9100 시리즈 또는 MF9300 시리즈를 사용중인 경우, 프린터의 제어판에서 IPv6를 설정할 수 있다 하더라도, IPv4만 네트워크 연결을 지원합니다.
USB를 통해 연결된 프린터가 플러그 앤 플레이로 자동 등록되는 경우, 단방향 인쇄 연결을 사용하는 프린터가 등록되고 인쇄 중 색상 등의 문제가 발생할 수 있습니다. 양방향 인쇄 연결이 필요한 디바이스를 등록하려면 Canon Printer Setup Utility 또는 다음 명령을 사용해야 합니다.
# /usr/sbin/lpadmin -p [등록할 프린터 이름] -P [PPD 파일 경로] -v cnusbufr2:/dev/usb/lp0 -E
사용 중인 배포 버전에 따라, "/dev/usb/lp*"를 장치 URI로 지정하여 프린터 스풀러에 USB 프린터를 등록하는 경우 "프린터가 연결되지 않음"이라는 오류가 나타나며 인쇄가 되지 않을 수 있습니다. 이 문제를 해결하려면 다음 명령을 사용하여 프린터별 이름을 장치 URI로 지정합니다.
예: MF4600 시리즈 사용 시
(1) 장치 URI를 표시하십시오.
# /usr/sbin/lpinfo -v
direct usb://Canon/MF4600%20Series%20(FAX)
direct usb://Canon/MF4600%20Series%20(PCL5e)
direct usb://Canon/MF4600%20Series%20(PCL6)
direct usb://Canon/MF4600%20Series%20(UFRII%20LT)
(2) 프린터를 등록하십시오.
# /usr/sbin/lpadmin -p MF4600_USB -P /usr/share/cups/model/CNRCUPSMF4600ZK.ppd -v usb://Canon/MF4600%20Series%20(UFRII%20LT) -E
LIPSLX, UFR II/UFRII LT (US) 및 UFR II/UFRII LT (KR) 드라이버 설치 패키지를 사용하여 2개 이상의 드라이버를 설치하고, 이 중 1개 드라이버만 업데이트 할 경우에는 오류가 발생합니다. 이 문제는 설치한 드라이버를 모두 업데이트 하여 해결할 수 있습니다.
환경에 따라 Canon Printer Setup Utility에 원격 프린터가 표시될 수 있습니다. 또한 표시되는 원격 프린터를 삭제하지 못할 수 있습니다.
USB를 통해 연결된 프린터가 Canon Printer Setup Utility에서 등록된 경우, 양방향 인쇄 연결이 필요한 프린터라고 하더라도 단방향 인쇄 연결을 사용하는 프린터가 등록될 수 있습니다. 이 경우 USB 케이블을 다시 연결하고 Canon Printer Setup Utility에서 프린터를 다시 등록하십시오.
USB를 통해 프린터가 연결된 경우, 프린터가 등록되었을 때 디바이스 URI가 표시되지 않을 수 있습니다.
이 경우 디바이스의 제어판이나 리모트 UI를 사용하여 디바이스 설정에서 [드라이버레스 인쇄 사용], [AirPrint 사용] 또는 [Mopria 사용]을 비활성화하십시오.
드라이버를 작동하는 데 필요한 라이브러리가 컴퓨터에 설치되지 않은 경우, 컴퓨터가 인터넷에 연결되어 있으면 필요한 라이브러리가 자동으로 다운로드됩니다. 컴퓨터가 인터넷에 연결되어 있지 않으면 드라이버 설치 프로세스가 취소됩니다.
설치 패키지를 두 번 클릭하여 드라이버를 설치하는 경우, 환경에 따라 설치가 올바르게 수행되지 않을 수 있습니다. 이 경우 설치 프로그램을 사용하여 드라이버를 설치하십시오.
2. 설치 중 제한(배포별)
Fedora
드라이버 설치, 드라이버 업그레이드 또는 설치 프로그램 실행 시 yum 명령이 사용되지 않는다는 경고가 표시될 수 있으나, 설치는 올바르게 수행되고 아무 문제도 발생하지 않습니다.
Debian
필수 라이브러리 다운로드가 실패할 수 있으며 드라이버를 설치하지 못할 수 있습니다. 이러한 상황이 발생할 경우 슈퍼 유저 권한을 사용하여 다음과 같이 운영 체제 패키지에 대한 다운로드 대상 목록(/etc/apt/sources.list)을 편집하고 저장하십시오.
다음의 미러 리다이렉터 서비스 URL을 다운로드 대상으로 추가하십시오.
deb http://httpredir.debian.org/debian [운영 체제 버전 코드명] main
예(Debian 9.0): deb http://httpredir.debian.org/debian stretch main
#를 다운로드 대상으로 지정하여 사양을 취소하는 "deb cdrom: ..." 줄의 시작에 "CD/DVD"를 다음과 같이 추가하십시오.
# deb cdrom: ...
3. 인쇄 중 제한(모든 배포 공통)
환경에 따라 관리자 권한으로 응용 프로그램을 시작하지 못할 수 있습니다. 이러한 경우 다음 명령을 실행하여 응용 프로그램을 시작하십시오.
$ xhost +SI:localuser:root
인쇄 시 인쇄 대기열에 보유할 수 있는 최대 파일 수는 CUPS 사양에 따라 500개 입니다. 500번째 파일 이후 대기 파일은 무시됩니다.
StarSuite7/OpenOffice로 생성된 문서 인쇄 시 [일반] 시트의 [페이지 레이아웃]에서 여러 페이지/매수를 지정할 경우, CUPS 모듈에 의한 작동 원인으로, 여러 페이지 및 출력에 설정이 올바르게 할당되지 않습니다.
OpenOffice.org 또는 StarSuite에 지정된 매수에 따라 생성된 PostScript 파일은 [cngplp2] 화면(드라이버 UI)의 [매수]에서 지정된 값이 아닌, PostScript 파일 생성 시 설정한 매수에 영향을 받습니다.
OpenOffice.org의 Writer와 같은 응용프로그램의 인쇄 화면에서 용지 공급원 설정을 지정하는 경우, 응용프로그램을 통해 이루어진 설정은 프린터 드라이버 UI 설정에 의해 재정의됩니다. 원하는 용지 공급원에서 인쇄하려면, 프린터 드라이버 UI에서 미리 용지 공급원을 지정하거나 명령줄에서 인쇄합니다.
드라이버 UI 또는 명령줄에서 TIFF 또는 JPEG 이미지를 인쇄할 경우, 이미지가 여러 페이지에 나뉘어 인쇄될 수 있습니다. 이 문제는 GIMP와 같은 응용프로그램에서 이미지를 PostScript 파일로 출력한 다음, 드라이버 UI 또는 명령줄에서 PostScript 파일을 인쇄하여 해결할 수 있습니다.
입력 또는 텍스트 보기 값을 설정한 후, 대화상자 우측 상단의 [X] 버튼을 클릭하여 완료하면, 이 값은 [확인] 버튼을 클릭할 경우와 동일하게 유효한 값으로 처리됩니다. 설정된 값을 비활성화 하려면, [취소] 버튼을 클릭합니다.
인쇄 시 32바이트를 초과하는 문서 이름을 지정할 경우, 문서 이름의 문자열이 드라이버에 의해 33번째 바이트부터 삭제되고, 장치에 표시된 문서 이름은 최대 32바이트가 됩니다.
[cngplp2] 화면 또는 명령줄에서 PDF 이미지 파일을 인쇄하는 경우, 이미지에 따라 인쇄 결과가 검게 나타날 수 있습니다.
사용 중인 환경에서 Adobe Reader 9를 사용할 수 있는 경우, 인쇄 시 [고급 인쇄 설전] 대화 상자에서 [프린터에서 색상 결정] 또는 [이미지로 인쇄]를 선택하여 이 문제를 해결할 수 있습니다.
Adobe Reader 8을 사용하여 PDF 파일을 인쇄할 경우, 일부 이미지 데이터가 인쇄되지 않을 수 있습니다. 이 문제는 Adobe Reader 7 또는 9를 사용하여 인쇄하거나, PostScript 옵션에서 레벨 3을 설정하여 해결할 수 있습니다.
CUPS 버전에 따라 lpoptions에 "#" 또는 "\" 사용 시 올바르게 인쇄되지 않을 수 있습니다. 이 문자들을 사용하지 마십시오.
CUPS 버전 1.6.3 이하를 사용하는 경우 컴퓨터와 디바이스를 USB를 통해 연결하여 프린터가 자동으로 등록된 경우 두 번째부터 데이터가 올바르게 인쇄되지 않을 수 있습니다. Canon Printer Setup Utility를 사용해 프린터를 다시 등록하여 이를 방지할 수 있습니다.
인쇄 처리 시, 드라이버 UI에서 설정이 변경된 경우, 변경된 설정이 인쇄 결과에 반영됩니다.
[부서 ID 관리 인증]/[보안 인쇄 인증]이 올바르게 설정되어 있지 않은 경우 인증 기능을 사용하지 못하거나 인쇄를 수행하지 못할 수 있습니다. 디바이스가 인증 정보 암호화를 지원하는 경우 [모드 2]를 설정하십시오. 그렇지 않으면 [모드 1]을 설정하십시오.
OpenOffice.org에서 인쇄할 때, 드라이버 UI의 [매수]에서 여러 매수를 지정할 경우, [회전]과 같은 일부 마무리 기능이 제대로 작동하지 않을 수 있습니다.
[Finisher-Q3] 또는 [Saddle Finisher-Q4]가 부착되어 있고 A4, Letter, 또는 Legal을 용지 크기로 지정할 경우, [마무리] 시트에서, [제본 위치]를 [짧은 가장자리(위쪽)]으로 설정하고 [스테이플 위치]를 [상단(이중)]으로 설정하였거나, [제본 위치]를 [짧은 가장자리(아래쪽)]으로 설정하고 [스테이플 위치]를 [하단(이중)]으로 설정한 상태에서, 인쇄 시도 시 문서가 제대로 인쇄되지 않습니다.
[cngplp2] 화면 또는 명령줄에서 PDF 이미지 파일을 인쇄하는 경우, 이미지에 따라 인쇄 결과가 검게 나타날 수 있습니다. 다음의 방법 중 하나로 이를 방지할 수 있습니다.
(1) GIMP 등의 응용프로그램에서 인쇄하십시오.
(2) 파일을 PostScript 파일로 내보낸 후 출력 PostScript 파일을 [cngplp2] 화면에서 인쇄하십시오.
[보안 인쇄]를 출력 방법으로 지정하고 드라이버 UI에서 [설정 저장]을 클릭한 후 출력 방법을 [인쇄]로 변경하면, [보안 인쇄]를 사용하여 출력한 문서의 이름이 프린터 작업 로그에 표시됩니다. 이 문제는 출력 방법을 [보안 인쇄]에서 [인쇄]로 변경 시 [인쇄] 버튼이 아닌 [설정 저장] 버튼을 사용하여 인쇄하는 방식으로 해결할 수 있습니다.
GTK(GIMP Toolkit)의 버전에 따라, 이해할 수 없는 글자가 화면에 일부 표시될 수 있으나, 이는 설정된 기능과 값의 문제를 나타내는 것은 아닙니다. 해당 텍스트 영역을 변경하여 이 문제를 해결합니다.
PDF 문서를 데스크톱이나 명령줄에서 직접 지정하여 인쇄하는 경우 문서가 올바르게 인쇄되지 않을 수 있습니다. PDF 문서를 인쇄할 때는 Acrobat Reader 또는 Adobe Reader에서 인쇄하는 것이 좋습니다.
Adobe Reader 7.0.x를 사용하고 인쇄 화면에서 용지 크기, 용지 공급원, 양면 인쇄 등의 설정을 변경하는 경우 이 옵션들이 프린터 명령에 자동으로 추가됩니다.
하지만 이 설정들은 명령 옵션으로 인식할 수 없기 때문에 작동하지 않습니다. 이 문제를 해결하려면 -o를 사용해 각 명령 옵션을 분리하십시오.
[변경 전]
-o InputSlot=Manual,Duplex=DuplexNotumble
[변경 후]
-o InputSlot=Manual -o Duplex=DuplexNoTumble
Adobe Reader 8.1.2로 양면 인쇄를 수행할 경우 Adobe Reader 8.1.2의 인쇄 속성에서 [양면 인쇄]를 [설정(짧은 가장자리 제본)]으로 지정하면, 문서가 긴 가장자리 제본으로 양면에 인쇄됩니다. 이러한 문제는 프린터 드라이버 UI로 문서를 인쇄하여 방지할 수 있습니다.
인쇄 데이터의 환경과 유형에 따라, 장치 끝점의 프린터 데이터 오류로 인해 MF4270 또는 L90/L160/L230 프린터가 인쇄를 수행하지 못하는 경우가 있을 수 있습니다. 이 문제는 장치 끝점에서 발생하는 타임아웃 오류 때문에 발생합니다. 이는 장치에서 오류 타임아웃 설정을 해제하여 방지할 수 있습니다.
배너 페이지 인쇄 시 지정된 부수의 배너 페이지를 인쇄할 수 있습니다.
밝기 및 감마 보정 설정은 인쇄 결과에 반영되지 않을 수도 있습니다.
디바이스가 USB를 통해 연결되어 있는 경우, 같은 데이터를 계속해서 인쇄 시도하면 두 번째 이후부터 데이터가 올바르게 인쇄되지 않을 수도 있습니다. 이 문제는 디바이스와 운영 체제 간 데이터 전송 시 발생하는 불일치에 의해 발생합니다.
이 문제는 USB 케이블을 분리하고 USB 포트를 재설정한 후 다음 옵션을 추가하여 해결할 수 있습니다.
# /usr/sbin/lpadmin -p [등록용 프린터 이름] -o usb-no-reattach-default=true
CUPS 1.5 이전 버전을 사용하는 경우, USB 케이블을 분리하고 USB 포트를 재설정한 후 cnusbufr2를 다음과 같이 지정하여 문제를 해결할 수 있습니다.
# /usr/sbin/lpadmin -p [등록용 프린터 이름] -P [PPD 파일 경로] -v cnusbufr2:/dev/usb/lp0 -E
CUPS 버전 2.2.12/2.3.0을 사용하는 경우, [cngplp2] 화면에서 [기본값으로 설정]을 클릭하더라도 [이름]에서 선택한 프린터를 기본 프린터로 설정하지 못할 수 있습니다. 또한 [설정 저장]을 클릭하는 경우 기본 프린터가 변경될 수 있습니다.

응용 프로그램에서 인쇄하는 경우, 화면에 표시되는 드라이버 기능과 설정 이름이 환경에 따라 올바르게 표시되지 않을 수 있습니다.

인증 정보 암호화 기능을 지원하는 장치로 인쇄하는 경우, 각 배포마다 beecrypt 라이브러리가 필요합니다.
beecrypt 라이브러리 설치 명령의 예는 다음과 같습니다.
<Fedora>
# dnf install beecrypt beecrypt-devel
<Ubuntu14.04 - 15.10/Debian8>
# apt-get install libbeecrypt7 libbeecrypt-dev
<Ubuntu16.04 이후/Debian9 이후/UOS/Kylin OS>
# apt-get install libgcrypt20 libgcrypt20-dev
<NeoKylin OS>
# yum install libgcrypt libgcrypt-devel

이 경우, 다음 명령을 실행하여 라이브러리를 설치한 후 인쇄하십시오.
<Fedora>
# dnf install libjpeg-turbo
<Ubuntu/Debian/UOS/Kylin OS>
# apt-get install libjpeg62
<NeoKylin OS>
# yum install libjpeg-turbo

이 경우, 다음 명령을 실행하여 라이브러리를 설치한 후 인쇄하십시오.
